# Менеджер личных финансов

Консольное приложение на Java для учёта доходов и расходов. Поддерживает несколько пользователей, категории, бюджеты, статистику, переводы и импорт/экспорт операций.

## Требования

- Java 21;
- Maven 3.9 или новее.

## Сборка и запуск

Запуск из Maven:

```bash
mvn exec:java
```

Сборка исполняемого JAR и запуск:

```bash
mvn package
java -jar target/finance-manager-1.0.0.jar
```

После старта введите `help`. Для названий с пробелами используйте двойные кавычки: `"Коммунальные услуги"`.

## Команды

| Команда                                              | Назначение                                   | Пример                                 |
| ---------------------------------------------------- | -------------------------------------------- | -------------------------------------- |
| `register <логин> <пароль>`                          | Регистрация пользователя                     | `register ivan secret`                 |
| `login <логин> <пароль>`                             | Вход в аккаунт                               | `login ivan secret`                    |
| `logout`                                             | Завершение сессии                            | `logout`                               |
| `category add <income\|expense> <название>`          | Создание категории                           | `category add expense "Еда дома"`      |
| `category rename <income\|expense> <старое> <новое>` | Переименование категории, операций и бюджета | `category rename expense Еда Продукты` |
| `category list`                                      | Список категорий                             | `category list`                        |
| `income <категория> <сумма>`                         | Добавление дохода                            | `income Зарплата 80000`                |
| `expense <категория> <сумма>`                        | Добавление расхода                           | `expense "Еда дома" 1500`              |
| `budget set <категория> <сумма>`                     | Установка бюджета                            | `budget set Еда 10000`                 |
| `budget edit <категория> <сумма>`                    | Изменение бюджета                            | `budget edit Еда 12000`                |
| `budget remove <категория>`                          | Удаление бюджета                             | `budget remove Еда`                    |
| `budget list`                                        | Бюджеты и остатки                            | `budget list`                          |
| `stats [категория1 категория2 ...]`                  | Общая или выборочная статистика              | `stats Еда Такси`                      |
| `report-file <путь>`                                 | Отчёт в текстовый файл                       | `report-file report.txt`               |
| `transfer <логин> <сумма>`                           | Перевод другому пользователю                 | `transfer maria 500`                   |
| `export <файл.csv>`                                  | Экспорт операций в CSV                       | `export backup.csv`                    |
| `import <файл.csv>`                                  | Импорт операций из CSV                       | `import backup.csv`                    |
| `help`                                               | Справка                                      | `help`                                 |
| `exit`                                               | Сохранение и завершение                      | `exit`                                 |

Суммы должны быть положительными. Категорию нужно создать до добавления операции; неизвестная категория вызывает понятную ошибку. Категории сравниваются без учёта регистра.

## Пример сессии

```text
register ivan secret
login ivan secret
category add income Зарплата
category add expense "Коммунальные услуги"
income Зарплата 63000
expense "Коммунальные услуги" 3000
budget set "Коммунальные услуги" 2500
stats

Общий доход: 63000
Общие расходы: 3000
Бюджет по категориям:
Коммунальные услуги: 2500, Оставшийся бюджет: -500
exit
```

При расходах от 80% бюджета приложение предупреждает пользователя. Также выводятся предупреждения о превышении бюджета, расходах выше доходов и нулевом/отрицательном балансе.

## Хранение данных и CSV

Рабочие данные находятся в `data/` и не попадают в Git:

- `users.json` — логины, соль и хеши паролей;
- `wallet-<sha256>.json` — категории, операции и бюджеты одного пользователя.

Пароли не хранятся открытым текстом: используется PBKDF2WithHmacSHA256 с индивидуальной солью. Имя файла кошелька получает SHA-256 от логина, поэтому логины не конфликтуют. Запись выполняется во временный файл, затем атомарно перемещается на место.

Дата в JSON-кошельке имеет формат `dd.MM.yyyy`. CSV предназначен для обмена и имеет вид:

```csv
type,category,amount,date
EXPENSE,"еда дома",1500,2026-11-19
```

Импорт сначала полностью проверяет CSV и затем добавляет операции, поэтому неверный файл не изменит кошелёк частично.

## Архитектура

```text
ru.platonso.finance
├── model       Wallet, Transaction, User, BudgetStatus
├── exception   Ошибки приложения и валидации
├── storage     Интерфейсы репозиториев и JSON-файлы
├── service     Авторизация, кошелёк, отчёты, оповещения, CSV, переводы
├── cli         Разбор команд, сессия и вывод в терминал
└── Main        Сборка зависимостей и запуск
```

`Wallet` защищает правила предметной области: операция возможна только в существующей категории, суммы и бюджеты положительны. Сервисы не хранят текущую сессию; она находится в CLI. Сервис отчётов возвращает данные, а CLI только отображает их.

## Тестирование и CI

```bash
mvn test       # тесты
mvn verify     # тесты, проверка форматирования и сборка
```

В проекте 25 тестов: авторизация, кошелёк, отчёты, оповещения, CSV, файловое хранилище и переводы. GitHub Actions запускает `mvn --batch-mode verify` на каждом push и pull request.

## Принятые решения

- Для денег используется `BigDecimal`; суммы выводятся без экспоненциальной записи.
- Баланс вычисляется из операций и не дублируется отдельным полем.
- Категории нормализуются через `trim()` и сравнение без учёта регистра.
- Токенайзер CLI поддерживает названия в двойных кавычках.
- Перевод проверяет получателя, самоперевод и достаточность средств до изменения кошельков.
