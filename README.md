# Менеджер личных финансов

Консольное приложение для нескольких пользователей. Данные хранятся в памяти до завершения, затем сохраняются в файле.

## Требования и запуск

Java 17+ и Maven 3.9+.

```bash
mvn exec:java
```

| Команда          | Пример                                                        |
| ---------------- | ------------------------------------------------------------- |
| Регистрация/вход | `register ivan secret`, `login ivan secret`                   |
| Категория        | `category add expense "Коммунальные услуги"`                  |
| Операция         | `expense "Коммунальные услуги" 3000`, `income Зарплата 20000` |
| Бюджет           | `budget set Еда 4000`, `budget list`                          |
| Отчёт            | `stats Еда Такси`, `report-file report.txt`                   |
| Обмен            | `export backup.csv`, `import backup.csv`                      |
| Перевод          | `transfer maria 500`                                          |




Тесты запускаются `mvn test`, полная проверка `mvn verify`.
